# GG Times Content Maker Script

Автоматизированная система (Content Factory) для сбора игровых новостей из Telegram-каналов, их рерайта с помощью ИИ (OpenAI GPT-4o-mini или Gemini 1.5 Flash) и публикации в ваш канал с сохранением медиафайлов и продвинутым форматированием.

## 🚀 Основные возможности
- **Сбор контента**: Слушает указанные Telegram-каналы в реальном времени.
- **Интеллектуальный рерайт**: Использует промпт для создания дерзкого игрового контента.
- **Поддержка альбомов**: Группирует несколько изображений/видео из одного поста в один пост-альбом.
- **Продвинутое форматирование**:
    - Автоматические **желтые цитаты** (`blockquote expandable`) для списков более 4-х элементов.
    - Жирный шрифт для названий.
    - Умная расстановка эмодзи.
- **Двойной ИИ-движок**: Основная работа через GPT-4o-mini, автоматический откат на Gemini при сбоях.

## 🛠 Настройка (Файл .env)

Все настройки хранятся в файле `.env`. Скопируйте содержимое из `.env.example` и заполните следующие поля:

### 1. API Ключи ИИ
- `OPENAI_API_KEY`: Ваш ключ от OpenAI.
- `GEMINI_API_KEY`: Ваш ключ от Google AI Studio.

### 2. Ключи Telegram (User Side — для сбора)
Нужны для того, чтобы скрипт мог "читать" другие каналы от вашего имени. Получить можно на [my.telegram.org](https://my.telegram.org).
- `TG_API_ID`: ID приложения.
- `TG_API_HASH`: Хеш приложения.
- `TG_SESSION_STRING`: Строка сессии (генерируется через `get_session.py`).

### 3. Бот и Канал (Bot Side — для публикации)
- `TELEGRAM_BOT_TOKEN`: Токен вашего бота из @BotFather.
- `TELEGRAM_CHANNEL_ID`: ID вашего канала (например, `-100...`).

### 4. Источники контента
- В файле `config.py` или поле `SOURCE_CHANNELS` (в зависимости от версии) укажите список юзернеймов каналов без `@`.

## 📝 Редактирование Логики

### Как изменить Промпт (Тон и стиль текста)
Все настройки "личности" бота находятся в файле:
`processing/llm_router.py` -> свойство `self.prompt`.
Там можно изменить правила:
- Как выделять названия.
- Когда использовать цитаты.
- Какой сленг использовать.

### Как изменить условия для списков (Желтая полоска)
В том же файле `processing/llm_router.py` в промпте указано правило №3 про `blockquote expandable`. Если вы хотите, чтобы желтая полоска появлялась, например, от 3-х пунктов, просто измените число в тексте промпта.

## ⚡️ Быстрый старт на новом устройстве

Если вы скачали проект на новый компьютер, выполните эти шаги:

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/LoLerTV/GG_Times_ContentMaker.git
   cd GG_Times_ContentMaker
   ```

2. **Создайте файл конфигурации**:
   Просто скопируйте шаблон:
   ```bash
   copy .env.example .env
   ```

3. **Заполните данные**:
   Откройте созданный файл `.env` и впишите свои API ключи и ID канала.

4. **Запустите программу**:
   Самый простой способ — через Docker:
   ```bash
   docker-compose up --build
   ```
   *Все зависимости и база данных настроятся автоматически внутри контейнера.*

## 📦 Запуск

### Способ 1: Через Docker (Рекомендуется)
1. Убедитесь, что Docker Desktop запущен.
2. В папке проекта выполните:
   ```bash
   docker-compose up --build
   ```

### Способ 2: Локально
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите базу данных PostgreSQL + pgvector.
3. Запустите скрипт:
   ```bash
   python main.py
   ```

## ⚠️ Важно для GitHub (Безопасность)
**Никогда не пушьте файл `.env` в публичный репозиторий!**
Если вы случайно это сделали:
1. Используйте `git rm --cached .env`.
2. Добавьте `.env` в `.gitignore`.
3. Перевыпустите (Revoke) API ключи, если они попали в сеть.

## 🗂 Структура проекта
- `ingestion/`: Сбор данных (Telegram).
- `processing/`: Логика ИИ, эмбеддинги и дедупликация (чтобы новости не повторялись).
- `distribution/`: Публикация в ваш канал.
- `db/`: Модели базы данных и миграции.
